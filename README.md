## 反馈问题

1. 先在 [Issues](https://github.com/yldm-tech/taptapgo-app/issues?q=is%3Aissue) 里搜一下，看看有没有人报过同样的问题。有的话点个 👍，或者补充你的情况。
2. 没有的话，[新建 Issue](https://github.com/yldm-tech/taptapgo-app/issues/new/choose)，选「问题反馈」或「功能建议」，按表单填写。

写清楚这几点，我们能更快修好：

- 用的是哪个平台：网页版、Windows、macOS、iPhone / iPad 还是 Android；
- 版本号：在「我的 › 关于」里，或者页面左上角标志旁边；
- 怎样一步步重现问题，你期望看到什么，实际发生了什么；
- 截图或录屏会很有帮助。

> [!IMPORTANT]
> Issues 是公开的，任何人都能看到。**请不要贴出邮箱、密码、兑换码、订单号或孩子的个人信息。** 账号、付款、退款和隐私相关的问题，请发邮件到 [hello@yldm.ai](mailto:hello@yldm.ai)，或者用官网的[意见反馈](https://taptapgo.yldm.ai/feedback)。
>
> 安全漏洞请不要公开提交，按 [SECURITY.md](SECURITY.md) 里的方式私下告诉我们。
