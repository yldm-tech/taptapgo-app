# TapTapGo

**小さなタコの相棒と冒険しながら、楽しくタッチタイピングを身につけよう。**

子ども、家族、学校のためのタイピングアドベンチャー。ステージマップ、20 種類以上のタイピングミニゲーム、単語学習、標準テスト、修了証を用意しています。英語、中国語のピンイン、日本語、韓国語、フランス語、ドイツ語、スペイン語、ロシア語、プログラミング言語の練習に対応しています。

## 不具合の報告・機能の提案

1. まず[既存の Issue](https://github.com/yldm-tech/taptapgo-app/issues?q=is%3Aissue) を検索してください。同じ内容があれば、リアクションや追加情報でお知らせください。
2. 見つからない場合は、[新しい Issue](https://github.com/yldm-tech/taptapgo-app/issues/new/choose) を開き、不具合報告または機能提案のフォームに記入してください。

次の情報を添えていただけると、確認がスムーズになります。

- 利用しているプラットフォーム：ブラウザ、Windows、macOS、iPhone / iPad、Android。
- アプリのバージョン：**Me › About** または画面左上のロゴ付近で確認できます。表示名は利用言語によって異なります。
- 再現手順、期待した動作、実際に起きたこと。
- 必要に応じて、スクリーンショットや画面録画。

> Issue は誰でも閲覧できます。**メールアドレス、パスワード、引き換えコード、注文番号、お子さまの個人情報は記載しないでください。** アカウント、お支払い、返金、プライバシーに関するお問い合わせは、[hello@yldm.ai](mailto:hello@yldm.ai) または公式サイトの[お問い合わせフォーム](https://taptapgo.yldm.ai/feedback)をご利用ください。
