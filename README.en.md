# TapTapGo

**Join Octo on a typing adventure. Play, explore and learn to touch type.**

[![Website](https://img.shields.io/badge/Website-TapTapGo-2563eb?style=flat-square)](https://taptapgo.yldm.ai) [![Web app](https://img.shields.io/badge/Play-Web_App-16a34a?style=flat-square)](https://taptapgo.yldm.ai/app) [![Downloads](https://img.shields.io/badge/Download-Desktop_%26_Mobile-7c3aed?style=flat-square)](https://taptapgo.yldm.ai/download) [![Feedback](https://img.shields.io/badge/Feedback-Issues-ea580c?style=flat-square)](https://github.com/yldm-tech/taptapgo-app/issues/new/choose) [![Release notes](https://img.shields.io/badge/Updates-Release_Notes-0891b2?style=flat-square)](https://github.com/yldm-tech/taptapgo-app/releases)

A typing adventure for kids, families and schools: a level map, more than 20 typing mini-games, vocabulary practice, standard tests and certificates. Practise English, Chinese pinyin, Japanese, Korean, French, German, Spanish, Russian and programming languages.

This repository collects **bug reports and feature requests** and publishes **release notes**. TapTapGo's source code is not hosted here.

## Report a problem

1. Search the [existing issues](https://github.com/yldm-tech/taptapgo-app/issues?q=is%3Aissue). If someone has reported the same problem, add a reaction or share more details.
2. Otherwise, [open an issue](https://github.com/yldm-tech/taptapgo-app/issues/new/choose) using the bug report or feature request form.

Please include:

- Your platform: web, Windows, macOS, iPhone / iPad or Android.
- The app version, found under **Me › About** or next to the logo in the top-left corner.
- Steps to reproduce, what you expected and what actually happened.
- Screenshots or a recording, if helpful.

> [!IMPORTANT]
> Issues are public. **Do not post email addresses, passwords, redeem codes, order numbers or a child's personal details.** For account, payment, refund or privacy questions, email [hello@yldm.ai](mailto:hello@yldm.ai) or use the [feedback form](https://taptapgo.yldm.ai/feedback).
>
> Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
